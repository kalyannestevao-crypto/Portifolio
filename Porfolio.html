Parte 1 – Programação Orientada a Objetos (POO)

Atributos e Métodos

Atributos são as características de um objeto (dados).

Métodos são as ações que o objeto pode realizar (funções).


                    class Pessoa {
                        String nome;
                        int idade;

                    void falar() {
                        System.out.println("Olá, meu nome é " + nome);
                    }

                    public static void main(String[] args) {
                        Pessoa p1 = new Pessoa();
                        p1.nome = "Ana";
                        p1.idade = 20;
                        p1.falar();
                    }
                }

Construtor

Construtor é um método especial usado para inicializar um objeto.

Ele define os valores iniciais dos atributos ao criar a instância.


                class Pessoa {
                    String nome;
                    int idade;

                    Pessoa(String nome, int idade) {
                        this.nome = nome;
                        this.idade = idade;
                    }

                    public static void main(String[] args) {
                        Pessoa p1 = new Pessoa("Carlos", 25);
                        System.out.println(p1.nome);
                    }
                }

Encapsulamento

Encapsulamento é o controle de acesso aos dados de um objeto.

Ele protege as informações, permitindo acesso apenas por métodos definidos.


                class Conta {
                    private double saldo;

                    public void depositar(double valor) {
                        saldo += valor;
                    }

                    public double getSaldo() {
                        return saldo;
                    }

                    public static void main(String[] args) {
                        Conta c = new Conta();
                        c.depositar(100);
                        System.out.println(c.getSaldo());
                    }
                }

Herança

Herança permite que uma classe herde atributos e métodos de outra.

Isso facilita o reaproveitamento de código e organização do sistema.


                class Animal {
                    void emitirSom() {
                        System.out.println("Som genérico");
                    }
                }

                class Cachorro extends Animal {
                    void latir() {
                        System.out.println("Au Au");
                    }

                    public static void main(String[] args) {
                        Cachorro c = new Cachorro();
                        c.emitirSom();
                        c.latir();
                    }
                }

Polimorfismo

Polimorfismo permite que um método tenha diferentes comportamentos.

Isso depende do objeto que está utilizando esse método.


                class Animal {
                    void emitirSom() {
                        System.out.println("Som genérico");
                    }
                }

                class Gato extends Animal {
                    @Override
                    void emitirSom() {
                        System.out.println("Miau");
                    }
                }

                public class Teste {
                    public static void main(String[] args) {
                        Animal a = new Gato();
                        a.emitirSom();
                    }
                }

Abstração

Abstração é a simplificação de um sistema complexo.

Ela mostra apenas o essencial e esconde detalhes desnecessários.


                abstract class Forma {
                    abstract double calcularArea();
                }

                class Circulo extends Forma {
                    double raio;

                    Circulo(double raio) {
                        this.raio = raio;
                    }

                    double calcularArea() {
                        return 3.14 * raio * raio;
                    }

                    public static void main(String[] args) {
                        Circulo c = new Circulo(2);
                        System.out.println(c.calcularArea());
                    }
                }

2. Reflexão Técnica

  • Por que POO é essencial para sistemas grandes?

    • POO é essencial para sistemas grandes porque organiza o código em partes menores (classes e objetos), facilitando a manutenção, reutilização e compreensão do sistema.


  • Quais problemas surgem sem encapsulamento?

    • Sem encapsulamento, os dados podem ser acessados e modificados de qualquer lugar, o que aumenta a chance de erros, falhas de segurança e inconsistências no sistema.


  • Quando herança pode se tornar um problema?

    • Herança pode se tornar um problema quando é mal utilizada, criando dependência excessiva entre classes, dificultando mudanças e tornando o sistema mais rígido e complexo.

Parte 3 – Banco de Dados

Conceitos

  • Dado vs Informação

    • Dado: valor bruto e não processado.

    Informação: dado processado e com significado.


  • Banco de Dados e SGBD

    • Banco de Dados é um conjunto organizado de dados.

    SGBD é o software que gerencia o banco de dados (ex: MySQL, PostgreSQL).


  • Chave Primária e Estrangeira

    • Chave Primária é um identificador único de cada registro.

    Chave Estrangeira é uma referência a outra tabela, criando ligação entre dados.


  • Relacionamentos (1:1, 1:N, N:N)

    • Relacionamentos definem como as tabelas se conectam: 1:1 (um para um), 1:N (um para muitos), N:N (muitos para muitos)


  • Normalização

    • Normalização é o processo de organizar os dados em tabelas para evitar duplicidade e inconsistências.

    Ela divide os dados corretamente, melhorando a integridade e eficiência do banco de dados.

Parte 4 – Integração (Visão de Sistema Web)

  • Como POO se conecta ao Banco de Dados?

    • POO se conecta ao banco de dados através de classes que representam tabelas, permitindo manipular dados usando objetos (ex: classe Cliente = tabela cliente).


  • O que é Backend?

    • Backend é a parte do sistema responsável pela lógica, processamento e comunicação com o banco de dados.


  • O que é Frontend?

    • Frontend é a interface com a qual o usuário interage, como páginas web, botões e formulários.


  • O que é API?

    • API é uma interface que permite a comunicação entre diferentes sistemas, enviando e recebendo dados.


  • O que é MVC?

    • MVC é um padrão de arquitetura que separa o sistema em Model (dados), View (interface) e Controller (controle), organizando melhor o código.


Fluxo Básico: Usuário → Interface → Backend → Banco de Dados

O usuário interage com a interface (frontend), que envia uma requisição ao backend. O backend processa a lógica e acessa o banco de dados, retornando a resposta para o usuário.
